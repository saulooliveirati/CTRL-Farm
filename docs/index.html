Dúvidas Comuns sobre o CTRL-Farm

Preciso instalar Docker ou configurar banco de dados no meu computador?

Não! Essa é uma das principais melhorias do instalador oficial v1.0.0-Beta. O instalador configura um PostgreSQL portátil ultraleve que roda silenciosamente em segundo plano consumindo menos de 40 MB de memória RAM, sem exigir Docker, WSL2 ou virtualização na BIOS.

O Windows SmartScreen exibiu uma tela azul ao abrir o arquivo. O que fazer?

Esse é o comportamento padrão do Windows Defender SmartScreen para executáveis independentes recentes que ainda não possuem milhares de downloads acumulados na Microsoft Store. Para prosseguir, basta clicar no texto sublinhado "Mais informações" e em seguida no botão "Executar assim mesmo". O instalador é 100% seguro.

Como funciona a solicitação e ativação de licença?

No primeiro acesso após instalar o CTRL-Farm, o sistema abrirá a tela inicial exibindo o seu ID de Instalação / Chave da Máquina. Basta copiar esse código e enviá-lo ao administrador. Ele gerará a sua chave criptográfica de liberação e você a colará no aplicativo para ter acesso total.

O sistema continuará funcionando se eu ficar sem internet?

Sim! O CTRL-Farm possui arquitetura local-first. Todo o seu estoque, impressoras, ordens de serviço e câmeras funcionam normalmente mesmo sem nenhuma conexão à internet.

Como instalar e executar no macOS se o Gatekeeper avisar que não pode verificar o desenvolvedor?

No Mac, baixe o arquivo CTRL-Farm.dmg, abra a imagem e arraste o app para a pasta /Applications. Se o macOS exibir o aviso padrão de segurança ("não foi possível verificar o desenvolvedor"), acesse Ajustes do Sistema > Privacidade e Segurança e clique em "Abrir Mesmo Assim", ou abra o Terminal e execute o comando: xattr -cr /Applications/CTRL-Farm.app. O aplicativo é 100% seguro e compatível com Apple Silicon (M1/M2/M3/M4) e processadores Intel.
