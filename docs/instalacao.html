Passo 2 — Instalação & Permissões do Sistema

Instruções para Windows e macOS

🪟 Instalação no Windows 10 / 11 (Bypass do SmartScreen)

Dê dois cliques no arquivo CTRL-Farm-Setup.exe. Como o aplicativo é uma versão Beta independente recente (sem certificado comercial caro da Microsoft), o Windows SmartScreen pode exibir uma tela azul dizendo: "O Windows protegeu o seu computador".

Como prosseguir com segurança no Windows:
  1. Na tela azul, clique no texto sublinhado: "Mais informações".
  2. Clique no botão que surge no canto inferior direito: "Executar assim mesmo".
  3. O instalador criará os atalhos no Desktop e Menu Iniciar em menos de 1 minuto.
🍎 Instalação no macOS (Arrastar para /Applications & Gatekeeper)

Dê dois cliques no arquivo baixado CTRL-Farm.dmg para abrir a imagem de disco do macOS.

Como prosseguir no macOS:
  1. Na janela que se abre, arraste o ícone CTRL-Farm para a pasta Aplicativos (/Applications).
  2. Abra o CTRL-Farm pelo Launchpad ou Spotlight (Cmd + Espaço).
  3. Aviso do Gatekeeper da Apple: Caso o macOS informe que o app "não pôde ser verificado pelo desenvolvedor", abra Ajustes do Sistema > Privacidade e Segurança, role a página até a seção Segurança e clique no botão "Abrir Mesmo Assim".
  4. Alternativa rápida via Terminal (opcional): se preferir, execute uma única vez:
    xattr -cr /Applications/CTRL-Farm.app

Passo 3 — Inicialização Automática e Janela Nativa

Ambiente industrial desktop pronto em Windows ou Mac

Ao término da instalação (ou clicando no ícone do aplicativo na Área de Trabalho ou no Launchpad), o supervisor nativo do CTRL-Farm executa silenciosamente em segundo plano:

  • ✔ PostgreSQL Portátil Local (Porta 5432 - consumo < 40 MB)
  • ✔ API NestJS & Sistema de Licenciamento (Porta 3001)
  • ✔ Interface Web Industrial Next.js (Porta 3000)
  • ✔ Servidor de Câmeras MediaMTX (Porta 8890)

Uma janela limpa e dedicada de desktop é aberta automaticamente no modo aplicação (sem barras nem distrações de navegador).

04

Passo 4 — Solicitação e Inserção da Chave de Licença

Desbloqueio com criptografia assimétrica RSA e isolamento multi-tenant

No primeiro acesso, a aplicação apresentará a tela de bloqueio e ativação do sistema:

Procedimento de Liberação:
  1. Na tela inicial do CTRL-Farm, localize o campo com o seu ID de Instalação / Chave da Máquina.
  2. Clique no botão "Copiar Código" e envie ao desenvolvedor/administrador por WhatsApp ou e-mail.
  3. O desenvolvedor fará a aprovação da sua empresa no Sistema ADM Gerente e lhe fornecerá a sua Chave Criptográfica de Licença.
  4. Cole a chave no aplicativo e clique no botão "Ativar Sistema".

✔ Assim que a chave for validada, o painel do CTRL-Farm será totalmente desbloqueado com todas as impressoras, bobinas, consignações e finanças ativas!
